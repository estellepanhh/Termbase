# 跨文化表达实验室使用与复核指南

表达实验室不是普通翻译框。它把术语库中已经发布的英语译法、来源证据、语境与文化提示组织成知识包，再让 DeepSeek 针对具体受众和传播场景生成可比较的表达方案。

## 使用流程

1. 在 `/lab` 搜索并选择1—5个已发布术语。
2. 检查每个术语的推荐英语、层级、分类、质量状态和来源摘要。
3. 输入10—1000字中文文本，选择受众、场景、风格和英语区域。
4. 生成报告，比较首选表达、备选表达、术语采用、文化风险、来源和局限。
5. 完成人工语言与学术复核后再用于正式传播。

首发版本只支持英语。分析结果不会写入数据库，也不会作为审核案例保存；刷新页面后结果即丢失。需要留档时可在报告顶部下载 Markdown 或 JSON。

## 结果边界

- 页面和导出文件都标明“AI生成、尚未人工复核”。
- `review_priority` 是复核优先级，不是准确率或置信度。
- 来源只显示服务端知识包中实际存在的记录；模型虚构的术语、译名或来源 ID 会被删除。
- 没有有效引用时，系统会发出警告并把复核优先级提升为高。
- AI仍可能产生表达不当、语境遗漏或语言风格问题，最终责任由人工审核承担。

## 运行与安全

默认按客户端 IP 限制为每分钟5次，使用单机内存存储。多实例部署必须配置 Redis 等共享限流存储，否则各实例配额互不共享。

服务默认依据直接连接的 `REMOTE_ADDR` 识别客户端，不信任任意 `X-Forwarded-For`。只有完成受信任反向代理和代理层来源限制后，才应启用真实客户端 IP 转发。

真实 DeepSeek Key 只放在 `term-backend/.env`，该文件必须保持 Git 忽略。不要把 Key 写入前端、API 文档、测试夹具或错误日志。

常见故障：

- 404：所选术语未发布或已不存在，重新搜索选择。
- 422：模型结构化输出异常，可重试一次任务。
- 429：请求过于频繁，等待限流窗口恢复。
- 502/503：DeepSeek 响应异常、超时或未配置，检查后端环境变量及网络。
