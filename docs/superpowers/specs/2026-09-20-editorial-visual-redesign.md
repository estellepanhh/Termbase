# 新中式数字人文视觉重构设计

## 目标

把现有页面从“功能可用但风格分散的管理型网站”重构为适合国家级大学生创新项目展示的文化研究平台。新视觉以“新中式学术编辑部”为主体，融入少量数字人文细节，同时保证移动端、儿童模式和大字模式属于同一套设计系统。

本次只调整前端信息层级、组件外观、响应式布局和阅读体验，不改变现有业务流程、API 契约、数据库结构与评审状态机。

## 设计原则

1. **文化感来自排版，不来自装饰堆砌。** 使用宋体标题、编辑式分栏、编号、细线和留白；不使用大面积传统纹样、仿古卷轴或过度印章。
2. **研究感来自信息层级。** 来源、状态、语种、修订和风险信息均有稳定视觉语法，避免普通后台仪表盘式卡片堆叠。
3. **技术感保持克制。** 数据统计、状态标签和交互反馈使用现代组件，但不能压过文化内容。
4. **全站一致。** 首页、检索、详情、实验室和工作台共享颜色、字体、间距、边框、按钮与状态组件。
5. **移动优先可用。** 320px 起不横向溢出；核心操作触控区域不小于 44px；双栏在合理断点下转为单栏。

## 视觉系统

### 色彩

- `ink-950`：近黑墨色，用于主标题与正文。
- `indigo-800`：墨青蓝，用于导航、主要按钮、研究模块和深色内容块。
- `vermilion-600`：朱砂红，用于当前状态、关键强调和少量文化标识。
- `paper-50`：温暖宣纸米白，作为页面背景。
- `paper-100` / `paper-200`：内容分区、悬停和边界层次。
- `jade-600`：玉石青，仅用于通过、完成和儿童友好提示。
- 风险色继续保留红/赭/绿语义，但降低饱和度以适配整体体系。

颜色必须达到 WCAG AA 正文对比度。朱砂红不承担长段正文。

### 字体与排版

- 中文标题：`Noto Serif SC`、`Source Han Serif SC`、宋体回退。
- 英文标题与数字：Georgia/系统衬线回退。
- 正文、表单与操作：Inter、`Noto Sans SC`、微软雅黑回退。
- 页面标题采用响应式 `clamp()`；正文默认 16px、行高 1.75。
- 英文眉题使用小号大写和加宽字距，但必须同时存在清晰中文标题。
- 内容宽度分为阅读宽度、常规宽度、工作台宽度三个层级，避免所有页面使用同一最大宽度。

### 形状、边框与层次

- 主体容器以 1px 纸灰边框和留白分层，减少通用阴影。
- 圆角控制在 4—12px；只有儿童模式提示和胶囊标签允许更圆。
- 按钮分为主要、次要、文字、危险四类；禁止各页面自行定义相近但不同的按钮。
- 状态、来源级别、语言和问题标签使用统一徽标组件。
- 装饰只允许细竖线、章节编号、极淡几何底纹和单个印记，不干扰阅读。

## 全局框架

### 桌面端页头

- 左侧为紧凑品牌标识：中文平台名为主，英文副标题为辅。
- 中部为五个主要导航，使用文字与细下划线表达当前状态。
- 右侧把语言和阅读模式整合为统一工具区，避免多个风格不一致的圆形按钮。
- 页头滚动时保持可见，但采用半透明纸色和细边界，不使用厚重阴影。

### 移动端页头

- 保留品牌简称、阅读偏好入口和菜单按钮。
- 导航、语言和完整阅读设置进入右侧抽屉；页头不同时塞入四至五个独立按钮。
- 375px 与 320px 下都不得挤压品牌或出现水平滚动。

### 页脚

- 增加项目定位、关键导航与“AI 结果需人工复核”提示。
- 保持轻量，不引入当前尚不存在的联系方式或备案信息。

## 页面设计

### 首页

- 首屏使用非对称编辑式布局：左侧项目定位、主标题和说明，右侧为大型检索入口与项目概览。
- 删除平均分布的普通营销卡片，改为“术语—证据—表达—评审”的研究流程带。
- 三层术语体系采用有编号的纵向编辑列表。
- 推荐术语采用横向文献卡，重点展示中文术语、推荐译法、定义和来源数量。
- 移动端首屏先呈现标题与检索，项目说明和数据依次下移。

### 术语检索

- 页面顶部以大搜索框为主视觉，筛选器成为次级工具。
- 桌面端筛选器使用紧凑横向工具栏；移动端使用可展开筛选区。
- 搜索结果由“独立大卡片”改为清晰的编辑式条目，强化术语、释义、推荐译法与来源数量的阅读顺序。
- 儿童模式下同一位置替换为儿童解释，并显示温和但不幼稚的“儿童解释”标识。

### 术语详情

- 顶部改为术语档案封面：中文名、推荐译法、层级、分类和数据质量组成一个整体。
- 正文按“译法—文化内涵—适用场景—跨文化提示—来源证据—关联概念”排序。
- 桌面端提供轻量章节导航；移动端保持单列自然阅读。
- 来源与证据更像文献注释而不是普通卡片，清晰区分来源元数据与原文摘录。
- 儿童模式将“给小朋友的话”置于首屏，专业内容保留在下方，不能删除或篡改原始研究资料。

### 跨文化表达实验室

- 页面改为“研究任务设置 → 知识依据 → 生成结果”的明确流程。
- 桌面端左侧为任务编辑器，右侧为报告纸张；移动端改为顺序流程并取消粘性结果栏。
- AI 结果使用研究报告版式，突出推荐表达、备选方案、风险与引用，不使用互不相关的卡片样式。
- “保存到工作台”和导出操作统一置于报告操作栏。

### 人工评审工作台

- 保留队列/详情结构，但从仪表盘风格改为研究档案工作台。
- 顶部统计简化为一条状态摘要，不使用五张同权重大卡片。
- 左侧案例队列强调标题、状态和当前版本；右侧详情呈现为一份可编辑研究档案。
- AI 建议与人工定稿继续并列对照，修订表单与状态操作明确分区。
- 移动端队列选择案例后把详情移到前景，并提供返回队列入口，避免用户滚动穿过整个队列。

## 儿童模式

儿童模式不是独立主题皮肤，而是标准设计系统的内容适配层：

- 保持墨青与米白基调，提高玉石青、暖黄的使用比例。
- 增加解释卡片的图形提示、间距和行高，但不使用卡通人物和廉价渐变。
- 优先展示已有儿童解释；缺失时明确使用普通释义，不伪造内容。
- 研究来源和专业内容仍可访问，只降低首屏认知负担。

## 大字模式

- 正文至少放大到 18—19px，行高不低于 1.75。
- 表单、按钮和触控区域同步扩大，不只放大文字。
- 标题采用单独比例，避免整体 CSS 缩放造成页面溢出。
- 与儿童模式可叠加，所有组合都必须通过 320px 移动端检查。

## 组件边界

新增或统一以下展示组件：

- `PageIntro`：眉题、页面标题、说明和可选操作。
- `SectionHeading`：章节编号、标题和辅助说明。
- `StatusBadge`：研究状态与风险状态。
- `EditorialCard`：有限场景使用的内容容器。
- `ReadingPreferences`：桌面工具区与移动抽屉共用状态。
- `MobileFilterPanel`：移动端筛选器。
- `ResearchFlow`：首页研究闭环展示。

组件只负责稳定视觉语法；页面内容和业务状态仍由现有功能组件管理。

## 响应式与无障碍验收

- 视口：320、375、390、430、768、1024、1440px。
- 页面不得产生非必要水平滚动。
- 所有可操作元素键盘可达，焦点样式清晰。
- 触控目标最小 44×44px。
- 抽屉打开后焦点受控，关闭后返回触发按钮。
- 尊重 `prefers-reduced-motion`。
- 阅读模式按钮具有 `aria-pressed`；视觉状态不能只依赖颜色。
- 文字、按钮和状态标签达到 WCAG AA 对比度。

## 测试策略

- 保留全部现有业务测试，视觉重构不得改变 API 调用和数据流。
- 为全局页头、移动导航、阅读偏好和移动筛选补充交互测试。
- 为每个核心页面增加关键结构测试，防止标题层级、主要操作和内容顺序退化。
- 使用生产构建验证 CSS 和 TypeScript。
- 最后进行桌面与移动视口人工视觉验收，重点检查中英文、儿童/大字四种组合。

## 明确不包含

- 不增加登录、权限或新的后端业务能力。
- 不替换现有品牌名称或项目研究定位。
- 不生成大面积插画、视频背景和复杂三维效果。
- 不引入沉重的第二套 UI 框架。
- 不为追求视觉效果隐藏来源、AI 未审核状态或研究风险提示。
