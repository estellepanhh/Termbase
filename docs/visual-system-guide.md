# 视觉系统维护指南

## 定位

界面采用“新中式学术编辑部 + 数字人文”风格。文化感主要来自宋体标题、编辑式分栏、编号、留白和朱砂色强调，不使用仿古纹理或大面积装饰图案。

## 核心变量

颜色和宽度定义在 `term-frontend/src/styles/tokens.css`：

- `--ink-950`：正文与标题墨色。
- `--indigo-800`：导航、主要按钮和研究模块。
- `--vermilion-600`：当前状态与关键强调。
- `--paper-50/100/200`：背景、分区和边界。
- `--jade-600`：成功状态和儿童友好提示。
- `--reading-width`、`--content-width`、`--workspace-width`：阅读、普通页面和工作台宽度。

新页面必须复用变量，不能在组件中另建近似品牌色。

## 排版和组件

中文标题优先 Georgia、Noto Serif SC、宋体回退；正文和表单使用 Inter、Noto Sans SC、微软雅黑。`components/editorial` 提供页面标题、章节标题和状态徽标。业务组件负责数据，编辑式组件只负责信息层级。

卡片仅用于确有独立边界的内容。普通章节优先使用细分隔线和留白。主要按钮使用墨青，重要警示使用朱砂；长正文不使用朱砂色。

## 响应式

- 1050px 以下主导航进入抽屉。
- 960px 以下表达实验室变单栏。
- 850px 以下术语档案章节导航改为横向链接。
- 820px 以下评审工作台在队列与详情之间切换。
- 700px 以下检索结果变为单列。
- 320px 为最小支持宽度，连续英文允许任意位置换行，正文禁止 `word-break: break-all`。

## 阅读模式

儿童模式通过 `.app-shell[data-child-mode]` 叠加，优先显示数据库已有儿童解释；没有时回退普通释义。大字模式通过 `.app-shell[data-large-text]` 调整正文、行高与控件尺寸，禁止使用整体缩放。两种模式必须能够同时开启。

## 禁止事项

- 不新增另一套 UI 框架。
- 不使用 `zoom` 或整体缩放实现大字模式。
- 不以颜色作为状态的唯一信息。
- 不隐藏 AI 未审核、历史数据待复核或来源信息。
- 不为视觉整洁删除语义标题、表单标签或键盘焦点样式。
