# 人工评审与案例工作台使用指南

## 研究定位

工作台用于把跨文化表达实验室的一次 AI 分析转化为可复核的研究案例。它不把 AI 输出直接视为权威译文，而是明确区分不可变的“AI 建议”和可持续追加的“人工修订”，形成可用于项目研究、案例讨论和成果统计的过程材料。

## 标准流程

1. 在“跨文化表达实验室”选择 1—5 个术语，填写原文、受众、场景和文体并生成报告。
2. 检查术语使用、文化风险和引用后，点击“保存到研究工作台”，填写案例标题。
3. 在工作台打开案例，对照 AI 建议与当前人工定稿，填写评审人、评审意见并勾选问题标签。
4. 点击“保存新修订”。每次保存都会产生新版本，旧版本不会被覆盖。
5. 草稿提交审核后，可批准或退回；批准案例可重新打开或归档；归档案例可恢复。
6. 使用状态、问题标签、评审人和关键词筛选案例，并按当前筛选条件导出 JSON 或 CSV。

## 状态和版本规则

- `draft`：可编辑，可提交审核。
- `pending_review`：可继续追加修订，可批准或退回草稿。
- `approved`：已形成阶段性定稿，仍可追加修订、重新打开或归档。
- `archived`：只读，可恢复为已批准。

页面保存时携带当前修订号。如果其他评审者已先保存，服务端返回 409；页面保留输入内容，刷新并比对新版本后再提交。AI 快照、人工修订和状态事件均为追加式记录，公共接口不提供删除功能。

## 导出与数据安全

JSON 适合后续程序分析，CSV 适合 Excel/WPS 统计。CSV 文件带 UTF-8 BOM，并对潜在公式单元格进行安全转义。导出内容仍可能包含研究文本，不应上传到未获授权的第三方平台。

当前版本没有账户系统。评审人姓名是自填研究字段，不能证明真实身份，因此系统仅适合本机或受控网络。正式公开部署前应增加统一身份认证、角色权限和操作审计。

## 初始化数据库

先备份数据库，再在后端目录执行：

```powershell
$env:FLASK_APP='termbase_app:create_app'
.\venv\Scripts\flask.exe db upgrade
.\venv\Scripts\flask.exe db current
```

当前评审工作台迁移版本为 `9f4c2a7b1d30`。迁移只新增 `review_cases`、`review_revisions`、`review_case_terms` 和 `review_events`，不改写已有知识记录。
